# Portfolio Website

Welcome to my personal portfolio website, showcasing my skills, experience, and client feedback as a Full-Stack Developer. This single-page portfolio, built with HTML, CSS, and JavaScript, highlights my freelance and personal projects, including a **Real-Time Chat Application**, **JournalismX**, **Netflix Clone**, **E-commerce App**, and **Amazon Frontend**. The site features a responsive design, animated sections, and a client reviews carousel powered by Owl Carousel.

## Features
- **Client Reviews Section**: A dynamic carousel showcasing feedback from clients and project stakeholders, including reviews for the Real-Time Chat App, JournalismX, Netflix Clone, E-commerce App, and Amazon Frontend. Built with Owl Carousel for smooth sliding and responsive design.
- **Experience Section**: Details my professional experience, including a freelance Real-Time Chat Application (January–March 2025) and personal/open-source projects (May 2024–Present).
- **Responsive Design**: Adapts seamlessly to mobile, tablet, and desktop screens, with tailored layouts for review cards and experience items.
- **Animations**: Engaging animations (e.g., `fadeInUp`, `flipInX`) powered by WOW.js and Animate.css for a polished user experience.
- **Dark Theme**: Sleek black background (`dark_bg`) with `#00C4FF` accents, based on the Roton Personal Portfolio Template.
- **GitHub Integration**: Links to open-source projects (E-commerce App, Netflix 2.0) for transparency and collaboration.

## Technologies Used
